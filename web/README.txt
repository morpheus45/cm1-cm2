PLATEFORME PÉDAGOGIQUE - UTILISATION

1. Ouvrez index.html dans un navigateur web
2. Sélectionnez :
   - Une matière (Français, Maths, Géo, Histoire, Sciences, EMC, Anglais)
   - Un niveau (CE1 à 3e)
   - Un trimestre (1, 2, ou 3)
3. L'élève verra :
   - Vocabulaire thématisé
   - Questions avec choix de réponses
   - Explications après vérification

Fichiers requis :
- ../contenus/ (dossier avec les fichiers JSON par matière et niveau)
